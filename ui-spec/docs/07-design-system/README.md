# 07 设计系统（Design System）：网页界面长什么样、怎么交互

> 本目录是所有项目网页前端的**设计规范**。[06-frontend.md](../06-frontend.md) 讲"怎么把前端做对"（工程、数据、安全），本目录讲"界面怎么设计才好用、好看、一致"。
>
> 主要参照：**Apple《Human Interface Guidelines》（HIG）**。HIG 写的是 Apple 平台的原生 App，本目录把其中与平台无关的原则和规则**翻译成网页（React + TypeScript + Vite）上可执行的做法**，并用 WCAG 2.2 补足网页特有的无障碍要求。
>
> 资料核对日期：2026-10-15。所有引用都在 [references.md](../../references.md) 的"设计系统"一节。凡是本规范自己选定的数值（例如动画时长、z-index），都会写明"本规范取值"，不冒充 Apple 或 W3C 的官方数字。

## 十条硬规则（违反任何一条，界面就不算完成）

1. **只用设计令牌**：颜色、字号、间距、圆角、阴影、动效、z-index 只能取自 `design-tokens.css`；组件代码里不出现裸色值（`#xxxxxx`、`bg-blue-500`）。
2. **浅色和深色都要能用**：默认跟随系统设置（`prefers-color-scheme`），两种模式都截图检查。
3. **对比度达标**：正文 ≥ 4.5:1，大字和控件边界 ≥ 3:1（WCAG 2.2 AA）；改颜色后运行 `templates/check-contrast.py`。
4. **字号用 `rem`**，不给 `html` 设置 px 字号；浏览器字号调大或页面放大到 200% 时内容不丢失。
5. **点击区域**：触屏上的主要控件至少 44×44 CSS 像素；任何控件不小于 24×24。
6. **系统字体栈**：不打包、不从网上加载 SF Pro 等 Apple 字体（许可证只允许用于 Apple 平台的界面设计稿）；也不使用 SF Symbols 图标。
7. **一页最多一到两个主按钮**；危险操作不做成主按钮。
8. **每个数据区域四种状态**：加载中、空、出错（可重试）、有数据——都要设计、都要验证。
9. **尊重"减少动态效果"**（`prefers-reduced-motion`）：位移、缩放类动画在该设置下关闭或改为淡入淡出。
10. **能用键盘完成全部操作，焦点始终可见**。
