# 7.6 图标与图片

## 7.6.1 不能用 SF Symbols

HIG 大量推荐 SF Symbols，但它**不能用于网页**：
- HIG《SF Symbols》要求使用者理解其条款，并禁止把符号（或易混淆的相似图形）用于 App 图标、Logo 或任何商标用途。
- HIG 规定所有 SF Symbols 都属于 Xcode 与 Apple SDK 许可协议中定义的"系统提供的图像"；该协议规定这类图像**仅授权用于开发运行在 Apple 品牌产品上的应用**（协议第 2.13 节，引用见 references）。网页可在任何设备上运行，不属于这个授权范围。
- 同理，不要使用 Apple Logo、Apple 硬件外形图等 Apple 拥有的图形（Apple《Copyright and Trademark Guidelines》）。

**本规范的做法**：使用一套许可证明确、允许商用的开源图标库，**全项目只用一套**。默认推荐 **Lucide**（ISC 许可证，React 包 `lucide-react`）；换用其他库（如 Heroicons、Tabler Icons、Material Symbols）写 ADR 并确认许可证。

## 7.6.2 HIG《Icons》中适用于网页的规则

- **简化、可识别**：细节太多的图标难以辨认；用与操作或内容直接相关的熟悉隐喻。
- **全应用视觉一致**：所有界面图标尺寸、细节程度、线条粗细、透视一致。混用不同图标库 = 违反此条。
- **图标粗细与相邻文字匹配**：除非想强调其中一方。
- **光学居中**：不对称图标（如下载箭头）几何居中会显得偏下，必要时微调。
- **选中态**：标准组件（标签栏、侧边栏）中的选中态由组件统一处理（例如线性图标 → 填充图标 + 强调色），不要每处单独做。
- **只在必要时在图标里放文字**，并且需要本地化。
- **用矢量格式（SVG）**。
- **自定义图标要有文字替代**（见下）。
- **包容性**：人物图形尽量中性，避免只在某些文化中能理解的图像。

## 7.6.3 常见操作的标准隐喻

HIG《Icons》"Standard icons"列出了常见操作对应的 SF Symbol。网页上用开源图标库中**同一隐喻**的图标，保持用户熟悉的含义：

| 操作 | HIG 使用的隐喻（SF Symbol 名称） | 网页上选择的图标应表达 |
|---|---|---|
| 新增 | `plus` | 加号 |
| 删除 | `trash` | 垃圾桶 |
| 编辑 / 重命名 | `pencil` | 铅笔 |
| 搜索 | `magnifyingglass` | 放大镜 |
| 筛选 | `line.3.horizontal.decrease` | 三条递减横线 / 漏斗 |
| 分享 | `square.and.arrow.up` | 向上箭头出框 |
| 更多 | `ellipsis` | 省略号（三个点） |
| 取消 / 关闭 | `xmark` | 叉号 |
| 完成 | `checkmark` | 对勾 |
| 撤销 / 重做 | `arrow.uturn.backward` / `.forward` | 回转箭头 |
| 复制 | `document.on.document` | 两张重叠的纸 |
| 打印 | `printer` | 打印机 |
| 账户 | `person.crop.circle` | 圆形人像 |
| 日历 | `calendar` | 日历 |

同一个隐喻全站只表示一个意思：垃圾桶只表示"删除"，不能同时表示"清空筛选"。

## 7.6.4 尺寸与用法

| 场景 | 图标尺寸（本规范取值） | 说明 |
|---|---|---|
| 正文行内、表格内 | 16px | 与 14–16px 文字搭配 |
| 按钮内（带文字） | 20px | 图标在文字前，间距 8px |
| 纯图标按钮 | 20px，按钮 44×44 | 点击区域靠内边距撑大 |
| 标签栏 / 侧边栏 | 24px | 配文字标签 |
| 空状态插图 | 48–64px | 用 `--ds-text-tertiary` 颜色 |

- 线宽统一（Lucide 默认 2px；在 16px 小尺寸下可统一改为 1.5，全站一致）。
- 图标颜色默认 `currentColor`，跟随文字颜色；状态图标用状态色，但**同时有文字**。
- 图标尺寸用 `rem` 或 `em`，随字号放大（HIG《Typography》：字号变大时有意义的图标也要变大）。

## 7.6.5 可访问性

- **纯图标按钮**：`<button aria-label="删除记录">`，图标 `aria-hidden="true"`；同时提供悬停提示（`title` 或自定义提示气泡）给鼠标用户。
- **装饰性图标**（旁边已有相同意思的文字）：`aria-hidden="true"`，不重复朗读。
- **表达状态的图标**（成功/失败）：旁边有文字，或用视觉隐藏的文字说明。
- 图标与背景对比度 ≥ 3:1（WCAG 1.4.11 图形对象）。

## 7.6.6 图片

- 有意义的图片写 `alt`（说明图片传达的信息，而不是"图片"）；装饰图片 `alt=""`（WCAG 1.1.1）。
- 指定 `width` / `height` 或 `aspect-ratio`，避免加载时页面跳动；列表中的图片 `loading="lazy"`。
- 深色模式下白底图片适当压暗（HIG《Dark Mode》）；Logo 等需要时提供浅/深两版（`<picture>` + `prefers-color-scheme`）。
- 不要用文字图片代替真实文字（WCAG 1.4.5）。
- 图表：颜色之外用形状、线型或直接标注区分系列；提供文字摘要或可切换的数据表（见 08）。
