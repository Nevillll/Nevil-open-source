# Nevil-open-source

个人开源项目合集。A collection of small open-source projects.

| 项目 Project | 说明 Description |
| --- | --- |
| [calendar-tasks-ui](calendar-tasks-ui/) | 任务（/work）和日程（/calendar）两页前端，内置 Mock 数据，无需后端即可运行。Task & calendar UI with built-in mock data, runs without a backend. |
| [ui-spec](ui-spec/) | UI 设计规范：前端工程规范、设计系统（布局与对齐、组件、交互、文案、无障碍、审查清单）、设计令牌。UI design spec & design tokens. |

## 快速开始 Quick start

```bash
cd calendar-tasks-ui
npm install
npm run dev   # http://localhost:3000
```
